## 🔧 第一步：数据库初始化（约3分钟）

**1. 启动MySQL服务**
```bash
# Windows PowerShell
net start mysql

# 或通过MySQL Workbench可视化启动
```

**2. 创建数据库**
```sql
CREATE DATABASE IF NOT EXISTS `generic_sys_admin` 
  DEFAULT CHARACTER SET utf8mb4 
  DEFAULT COLLATE utf8mb4_unicode_ci;
```

**3. 导入初始化脚本**
```bash
# 在MySQL命令行执行
SOURCE D:/ZYY Project/generic-sys-admin/sql/v1.0__init.sql;
```

**4. 验证数据库创建成功**
```sql
SHOW TABLES;
-- 应该看到：sys_user, sys_role, sys_user_role, sys_operation_log, template_entity, sys_menu, sys_role_menu
```

## 🔧 第二步：配置后端环境（约2分钟）

**1. 打开后端项目目录**
```
D:\ZYY Project\generic-sys-admin\backend\
```

**2. 配置数据库连接**
```yaml
# 文件：src/main/resources/application.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/generic_sys_admin?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false
    username: root
    password: 你的MySQL密码
  redis:
    host: localhost
    port: 6379
```

**3. 配置JWT密钥（必须修改）**
```yaml
jwt:
  secret: 你的256位密钥-至少32个字符-不要用这个默认值！
  expiration: 7200
  refresh-expiration: 604800
```

**4. 配置讯飞API（如需语音功能）**
```yaml
minimax:
  api-url: https://api.minimax.chat
  app-id: 你的AppId
  api-key: 你的APIKey
```

## 🔧 第三步：启动后端服务（约5分钟）

**1. 安装Maven依赖**
```bash
cd D:\ZYY Project\generic-sys-admin\backend
mvn clean install
```

**2. 启动后端**

## ❓ 常见问题快速排查

| 问题 | 解决方案 |
|------|---------|
| 启动报"端口被占用" | 改端口（application.yml的server.port）或关闭占用进程 |
| 数据库连接失败 | 检查MySQL服务是否启动，检查username/password是否正确 |
| npm install 报错 | 删除node_modules和package-lock.json，重新执行npm install |
| 登录404 | 检查后端是否启动在8080端口，确认VITE_API_BASE_URL配置正确 |
| Token过期太快 | 修改application.yml中jwt.expiration为更大数值（如72000） |
