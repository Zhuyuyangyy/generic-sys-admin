## 第五章 Bug修复记录

### Bug-001：MinIO不可用时启动失败

| 项目 | 内容 |
|------|------|
| Bug ID | BUG-001 |
| 严重程度 | 高 |
| 发现时间 | 2026-04-19 |
| 问题描述 | MinIO服务未启动时，Spring Boot启动失败，MinioClient Bean创建报错 |
| 修复方案 | 将MinioClient改为可选注入（required=false），新增MinioAvailability状态Bean，initBucket()捕获异常后设置available=false |
| 修复文件 | MinioConfig.java、MinioAvailability.java、MinioUtil.java |
| 验证结果 | ✅ 启动正常，MinIO不可用时自动降级到本地存储 |

### Bug-002：TTS无Key时接口报错

| 项目 | 内容 |
|------|------|
| Bug ID | BUG-002 |
| 严重程度 | 中 |
| 发现时间 | 2026-04-19 |
| 问题描述 | 未配置minimax.api-key时，调用TTS接口返回500错误 |
| 修复方案 | 新增MockTtsServiceImpl，实现TtsService接口，无Key时自动注入Mock实现 |
| 修复文件 | TtsService.java、MockTtsServiceImpl.java、MinimaxTtsUtil.java、TtsController.java |
| 验证结果 | ✅ 无Key时返回Mock路径，控制台彩色日志正常 |

### Bug-003：文件删除越权漏洞

| 项目 | 内容 |
|------|------|
| Bug ID | BUG-003 |
| 严重程度 | 高 |
| 发现时间 | 2026-04-19 |
| 问题描述 | 攻击者可通过构造URL删除MinIO其他Bucket的文件 |
| 修复方案 | deleteFile()增加bucketName校验，从URL解析的bucketName必须与配置一致 |
| 修复文件 | MinioUtil.java |
| 验证结果 | ✅ 非本Bucket的文件URL无法删除 |
