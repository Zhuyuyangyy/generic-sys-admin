## 三、数据流向图

### 3.1 用户登录数据流

```
[用户输入账号密码]
         │
         ▼
[POST /api/auth/login]
         │
         ▼
[JwtAuthFilter#doFilterInternal] ← 不拦截登录请求
         │
         ▼
[AuthController.login()]
         │
         ▼
[SysUserService.login(username, password)]
         │
         ├─ 查数据库：SELECT * FROM sys_user WHERE username=? AND is_deleted=0
         │
         ├─ BCrypt密码验证：passwordEncoder.matches()
         │
         └─ 查用户角色：SELECT role_id FROM sys_user_role WHERE user_id=?
         │
         ▼
[JwtUtil.createToken(userId, username, roles)]
         │
         ▼
[返回 {token, refreshToken, userId, username}]
         │
         ▼
[前端存储token到localStorage，跳转首页]
         │
         ▼
[后续请求携带 Authorization: Bearer <token>]
```

### 3.2 文件上传数据流

```
[用户选择文件，点击上传]
         │
         ▼
[POST /api/file/upload (multipart/form-data)]
         │
         ▼
[JwtAuthFilter验证Token → 放行]
         │
         ▼
[FileController.upload(file)]
         │
         ├─ 文件类型白名单校验
         ├─ 文件大小校验（≤10MB）
         │
         ▼
[minioUtil.uploadFile(file)]
         │
         ▼
[MinioAvailability.isAvailable()?]
         │
         ├─ YES → uploadToMinio()
         │         ├─ MinioClient.putObject()
         │         ├─ 生成UUID文件名
         │         └─ 返回 MinIO URL
         │
         └─ NO → uploadLocally()
                  ├─ 写入 {user.home}/.generic-sys-admin/uploads/
                  └─ 返回 /local-files/ 路径
         │
         ▼
[记录操作日志（OperationLogAspect）]
         │
         ▼
[触发 TTS 语音播报（异步）]
         │
         ▼
[返回 {url, filename, size, storageMode}]
```

## 四、技术架构决策记录

| 决策 | 选择 | 备选方案 | 理由 |
|------|------|----------|------|
| 主键生成策略 | 雪花算法(ID.ASSIGN_ID) | UUID/自增ID | 分布式环境下不冲突 |
| 认证方案 | JWT无状态 | Session | 支持分布式，无需Session共享 |
| ORM框架 | MyBatis-Plus | JPA/MyBatis | 条件构造器强大，减少SQL代码 |
| 前端状态管理 | Pinia | Vuex | 更轻量，Vue3官方推荐 |
| 对象存储 | MinIO | 阿里云OSS/七牛云 | 兼容S3，DOCKER一键启动 |
| 图表库 | ECharts | Highcharts/DataV | 国产开源，文档完善 |
| 降级策略 | 策略模式 | if-else | 符合开闭原则，便于扩展 |
