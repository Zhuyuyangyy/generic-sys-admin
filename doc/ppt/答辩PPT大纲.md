## 第3页：研究背景与意义
**标题**：一、研究背景与意义

**核心要点**：
- 📌 **现状问题**：传统管理系统开发存在"重复造轮子"问题——每个新项目都要从零开始搭建用户、权限、日志模块
- 📌 **行业痛点**：开发周期长（平均3-6个月）、代码质量参差不齐、维护成本高
- 📌 **研究目标**：设计一套"高复用、易扩展"的通用管理系统母版
- 📌 **创新价值**：可将新系统开发周期缩短50%以上，降低企业开发成本

---

## 第4页：相关技术介绍
**标题**：二、相关技术介绍

**核心要点**：
- 🔧 **后端**：SpringBoot3（自动配置）+ MyBatis-Plus（CRUD增强）+ MySQL8.0（事务支持）
- 🔧 **前端**：Vue3（Composition API）+ Element Plus（组件库）+ Pinia（状态管理）
- 🔧 **安全**：JWT无状态认证 vs 传统Session会话认证的对比
- 🔧 **亮点**：ECharts数据可视化 + Three.js 3D渲染 + Minimax TTS语音播报

## 第5页：系统架构设计
**标题**：三、系统设计——总体架构

**核心要点**：
- 🏗️ **前后端分离**：JSON RESTful API通信，职责清晰分离
- 🏗️ **分层设计**：Controller → Service → Mapper → MySQL 四层架构
- 🏗️ **核心模块**：通用基础设施(common) + 安全认证(security) + 权限控制(rbac) + 日志审计(log) + 语音播报(voice)

## 第6页：数据库设计
**标题**：三、系统设计——数据库设计（重点）

**核心要点**：
- 🗄️ **5张核心表**：sys_user（用户）、sys_role（角色）、sys_user_role（关联）、sys_operation_log（操作日志）、template_entity（模板实体）
- 🗄️ **ER图关系**：用户N:N角色 → 角色N:N权限
- 🗄️ **索引优化**：联合索引覆盖查询需求，避免回表
- 🗄️ **逻辑删除**：is_deleted字段实现软删除，保护数据安全

## 第7页：核心功能实现——JWT无状态RBAC
**标题**：四、系统实现——JWT + RBAC动态权限控制

**核心要点**：
- 🔐 **JWT签发**：用户登录→BCrypt验证密码→签发Token（含userId、permissions）→返回前端
- 🔐 **无状态验证**：每次请求携带Token，服务端不存储会话，横向扩展零额外开销
- 🔐 **动态权限**：用户→角色→权限→菜单 四级链路，权限精确到按钮级别
- 🔐 **代码展示**：展示JwtUtil.java核心签发/解析代码（3-5行关键代码）

## 第8页：核心功能实现——AOP日志审计
**标题**：四、系统实现——AOP操作日志审计

**核心要点**：
- 📝 **无侵入式记录**：通过@Aspect切面拦截所有Controller方法，自动记录操作日志
- 📝 **日志内容**：操作人、模块、方法名、请求参数、IP地址、耗时、结果
- 📝 **异步写入**：日志写入采用@Async异步处理，不影响主业务性能
- 📝 **日志脱敏**：密码等敏感字段自动过滤，只记录业务参数
